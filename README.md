DynamicCamLK
---
DynamicCamLK automates camera transitions (and settings) between the many different 'situations' that your character can find themselves in. Experience the game in a new way!

This version has been backported to the legacy WoW 3.3.5a client (**NOT CLASSIC**), but requires a custom library called [ConsoleXP](https://github.com/leoaviana/ConsoleXP) which brings some improvements into the game client. 

Please if you don't know what [ConsoleXP](https://github.com/leoaviana/ConsoleXP) is, read it's [README.md](https://github.com/leoaviana/ConsoleXP#ConsoleXP) file carefully.

Using this AddOn without [ConsoleXP](https://github.com/leoaviana/ConsoleXP) is not possible, as the World of Warcraft 3.3.5a client lacks several features that this addon utilizes. If you're afraid of [triggering warden](https://wowpedia.fandom.com/wiki/Warden_(software)) **DO NOT USE THIS ADDON**.

There might still be bugs as this has not been extensively tested. If you find any bug please report it.
